# 迫子算卦 · 周易六爻

只有一个文件 `index.html`，没有后端，所有数据都嵌在页面里。直接打开或放到 GitHub Pages 上就能用。

## 功能
- 顶部有两个标签：**六爻占卜** 和 **手相**，两个都已经做好。
- 六爻用三钱法：每次摇三枚铜钱，字面算 3、背面算 2，加起来 6 是老阴、7 是少阳、8 是少阴、9 是老阳，六次从下往上排成一卦。随机数用 `crypto.getRandomValues`，摇的时候有铜钱翻转动画。
- 结果页显示：本卦和变卦（卦名、卦序、全名、Unicode 卦符、六爻图、上下卦），朱熹的断卦规则（页面会写明这次用的是哪一条），要读的经文（分主和参），白话解读（总体、事业、财运、感情、健康），以及本卦全文（卦辞、彖、大象、六爻爻辞和小象，动爻标红）。有变卦时也能展开变卦全文。
- 最近 30 次卦例存在 `localStorage`（key 是 `pozi-suangua-history-v1`），可以点开回看。
- 页脚写着「仅供娱乐参考」。

## 朱熹断卦规则（出自《易学启蒙·考变占》）
| 动爻数 | 看哪段文字 |
|---|---|
| 0 | 本卦卦辞 |
| 1 | 本卦动爻的爻辞 |
| 2 | 本卦两个动爻的爻辞，以上面那爻为主 |
| 3 | 本卦卦辞和之卦卦辞，以本卦为主 |
| 4 | 之卦两个不动爻的爻辞，以下面那爻为主 |
| 5 | 之卦那个不动爻的爻辞 |
| 6 | 乾卦看「用九」，坤卦看「用六」，其他卦看之卦卦辞 |

## 数据来源
- 经传原文（简体）和卦的结构来自 iching.jic.io（`/data/jing.hans.json`、`/api/hexagrams.json`）。底本是殆知阁的公版《周易》，已与 Kanripo KR1a0001 逐字对勘，并按阮元刻《十三经注疏》本改正了 38 处。
- 白话解读是迫子自己写的（`data/baihua.tsv`）。

## 校验（脚本在 `scripts/`，结果在 `verification/`）
- **结构**：64 个卦的爻象全部不重复；每卦的爻象都等于「下卦三爻 + 上卦三爻」，八卦的爻象是单独写的一张表；文王卦序和一份独立整理的上下卦序列全部对上；`bian`（每爻变后得到的卦）64×6 项全部一致。另外又和 bollwarm/ZHOUYI 的上下卦逐卦比了一遍，全部一致（报告里那些「干」是繁转简时把「乾」误转成了「干」，不是真的不一致）。
- **经文**：卦辞和爻辞共 448 条，拿去跟维基文库《周易》逐条比（繁体先转成简体，去掉标点，维基文库里的异文标记 `{{另|…}}` 两种写法都算对）。实际比了 442 条，因为维基文库「否」卦页面的格式解析不了。442 条里有 425 条完全一样，剩下 17 条逐条看过了：大多是标点不同、异体字（祐/佑、祗/祇、纆/𬙊、洌/冽）、繁转简误转（乾→干），或者维基文库把坤卦的卦辞拆开写了；萃卦卦辞开头的「亨」和涣卦初六有没有「悔亡」，属于不同版本的写法差别，这里按 jic（阮刻本）保留。
- **改了两处**：革卦六二「巳日」改成「已日」，跟卦辞和维基文库保持一致；震卦六五「意无丧」改成「亿无丧」。
- **修了几处标点**：比卦六三小象、蹇卦彖、姤卦彖缺了一边引号；小畜初九、噬嗑九四、既济六二开头多了一个引号。这几处都已修正。
- 对照 bollwarm/ZHOUYI 有 39 处不同，基本都是 bollwarm 自己的错字，比如「见龙再田」「童豕之牿」。
- ctext.org 不允许自动抓取，所以没用它校对。

## 手相（已完成）
- **数据**：全部取自 `/workspace/fortune-research/data/`（喜顺儿整理的数据集），由 `scripts/build.py` 原样嵌进页面（另存一份到 `data/palm.json`），一条内容都没有自己加。
- **左手 / 右手切换**：示意图按 meta.json 的坐标画，左手取镜像（x → 1−x）。
- **照片（可选）**：用 `<input type=file accept="image/*" capture="environment">` 选图，只用本地 `URL.createObjectURL` 显示。不上传、不存储，页面没有任何网络请求。
- **示意图（SVG）**：手指位置取自 `palm_landmarks`；13 条掌纹按 `path_xy` 用 Catmull-Rom 平滑曲线画出，主线是实线，次要线是虚线。当前题目对应的线（`diagram_line_id`）会画成红色并标上名字，图下方写明这条线的起点和终点。问掌丘的题目会在各宫 / 丘的中心点打点，选中的点变红。
- **答题**：`questions` 表里的 19 道题一题一页，选项 id 来自 palm_line_forms、hand_types、special_marks、palm_mounts。每道题都可以选「不确定 / 跳过」，多选题则是「都没有 / 不确定」。单选题选完会自动跳到下一题，也可以点「上一题」回去改。
- **结果**：分 手型、主线、副线、特殊纹、掌丘 / 八卦宫 几组。每一项显示名称、形态、`reading_positive` 里的现代正面解读，以及能对上的引文（引文原文 + 白话 + 出处链接）。如果形态本身没有引文，就用这条线的引文。只展示数据集里已经给出的引文，`notes` 字段里那些旧说法一律不显示。生命线、健康线、掌中痣，以及备注里写了「不作健康判断」的项目，会加一句「这里不作任何健康判断，身体有不舒服请看医生」。页面底部放了喜顺儿给的免责声明。
- **保存**：最近一次结果存在 `localStorage` 的 `pozi-palm-last-v1`，只存手（左 / 右）、答案和时间，不存照片。下次打开会显示「上次手相结果 · 查看」。
- 页面源码：`site-src/template.html`（页面骨架和样式）和 `site-src/palm.js`（手相部分的逻辑）。测试脚本：`tools/test_palm.js`。
